# Git Exam Project

## Purpose
This project is created as part of a Git practical exam. It demonstrates the use of Git for version control, branching, merging, conflict resolution, and GitHub collaboration.

## Project Structure

- `app.py` – Main Python file with dummy functions.
- `README.md` – Project overview and structure.
- `CONTRIBUTING.md` – Guidelines for contributing.
- `.gitignore` – List of files and folders Git should ignore.
- `temp/` – (Ignored) Folder used for testing .gitignore.
